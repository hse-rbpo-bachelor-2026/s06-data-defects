# Резервный фрагмент

Этот каталог - для случая, описанного в карточке С06: если релевантный
фрагмент собственного проекта команды еще не готов к моменту переноса,
можно временно потренироваться здесь.

`ReserveDownloadHandler.cs` содержит упрощенную вариацию дефекта того же
класса, что REVIEW-3 в основном объекте, но в другом контексте – выгрузка
отчета по имени. Пройдите на нем полный цикл:
воспроизведите, найдите причину, классифицируйте, исправьте, докажите тестами,
оформите цепочку доказанного исправления.

Перенос хотя бы одной полной цепочки на собственный проект все равно должен
быть завершен к рубежу этапа проекта 3 (после С07) - резервный фрагмент это не отменяет,
а лишь позволяет не простаивать.
